# Manifesto da entrega

Esta pasta é um pacote limpo para publicação no GitHub do projeto Jungle Gaming Wagering Processor.

Antes de publicar:

1. Copie `.env.example` para `.env` apenas no ambiente local.
2. Suba PostgreSQL e LocalStack com Docker Compose.
3. Consulte `GUIA-DE-TESTES.md` para reproduzir a validação ponta a ponta.
4. Importe os arquivos de `postman/` para executar o fluxo HTTP.
5. Consulte `RELATORIO-FINAL.md` para o resultado consolidado.

O pacote não contém credenciais, dependências instaladas ou dados persistentes locais.
